# Ironhaven

A rain-soaked open-world crime game for the make.fun **gta6-01** bounty —
the most complete rendition of a GTA-style open world an agent can build:
a drivable city on foot and by car, traffic and pedestrians, car theft,
a wanted system and police, missions and a story, combat, a HUD with a
minimap, a start and a save. Everything in it is original: the city,
characters, vehicles, names, story, art, sound and music.

**The story.** Nadia "Nova" Kessler, a getaway driver fresh out of the
harbor races, works for fixer Otto Brandt to take Ironhaven back from
port kingpin Silas Crane — one job at a time. Ten story missions, each
with its own verb: hotwire, tail, breach, heist, race, boat chase,
rescue, takeover, smuggle, takedown.

**The city.** Six zones on one road grid you can drive end to end:
**Foundry Row** (furnaces and freight), **The Docks** (cranes and
containers), **Neon Mile** (arcades and clubs), **Old Town** (brick
lanes and informants), **Glass Spire** (towers and the Iron Bank) and
**The Yard** (container terminal and patrol boats).

**Systems.** Wanted 0–5 (roadblocks at 3+, AIR-1 helicopter at 4+,
SWAT vans at 5) · 6-weapon wheel · 3 crew abilities (Wren's drone,
Doc's field repair, Ferry's decoy) · territory + passive income ·
garage, 4 tiers · respect ranks · radio, 3 stations · day/night +
rain and fog · save/load · minimap with GPS route · traffic,
pedestrians, exploding cars.

Play it: open `game/index.html` in a desktop browser. No network
requests, no libraries — vanilla JS and canvas.

## Controls

| Key | Action |
|---|---|
| WASD / Arrows | Drive or walk |
| E | Steal / enter car, exit car |
| Space | Handbrake drift |
| Mouse + Click | Aim and shoot |
| Q | Weapon wheel (hold) |
| 1–6 | Weapons |
| 7 / 8 / 9 | Crew abilities (Wren / Doc / Ferry) |
| N | Current mission briefing |
| R | Cycle radio station |
| P | Pause |
| L | Save game |
| M | Mute |
